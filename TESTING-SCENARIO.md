### Критерии успешного прохождения:

✅ **Сброс (rst_n=0):** IP асинхронно устанавливается в 0x000 независимо от clock  
✅ **Инкремент (enable=1, jmp_enable=0):** IP увеличивается на 1 по каждому фронту clock  
✅ **Остановка (enable=0):** IP сохраняет текущее значение, инкремент не происходит  
✅ **Переход (jmp_enable=1):** IP загружается значением jmp_addr[11..0] по фронту clock  
✅ **Переполнение:** При инкременте 0xFFF → 0x000 (12-битный счетчик)  
✅ **Задержка:** Изменение IP происходит строго по положительному фронту clock (синхронно)
