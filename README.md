| Имя            | Назначение                            | Разрядность | Где используется             |
|----------------|----------------------------------------|------------|------------------------------|

### 5. Формат команды и декодер

#### 5.1. Поля первого слова команды (`IR[15..0]`)

| Имя             | Назначение                                               | Разрядность | Где используется           |
| --------------- | -------------------------------------------------------- | ----------- | -------------------------- |
| IR[15..0]       | Первое слово текущей команды (instruction0)              | 16          | Выход IR_reg               |
| addr_mode[1..0] | Режим адресации: addr_mode = IR[15:14]                   | 2           | УУ                         |
| opcode[7..0]    | Код операции: opcode = IR[13:6]                          | 8           | УУ, декодер                |
| operand1[2..0]  | Первый операнд: номер регистра Rn = IR[5:3]              | 3           | УУ, выбор первого регистра |
| operand2[2..0]  | Второй операнд: номер регистра Rm = IR[2:0] (если нужен) | 3           | УУ, выбор второго регистра |

#### 5.2. Второе слово команды (операнд) для MOV и JMP

Для двухсловных команд (`MOV adr, reg`, `MOV reg, adr`, `JMP adr`) используется второе слово в памяти программ:

| Имя                 | Назначение                            | Разрядность | Где используется          |
| ------------------- | ------------------------------------- | ----------- | ------------------------- |
| instruction1[15..0] | Второе слово двухсловной команды      | 16          | ПЗУ → регистр операнда    |
| mem_addr[11..0]     | Адрес в памяти: mem_addr = OPND[11:0] | 12          | УУ, формирование ADDR_bus |

#### 5.3. Режимы адресации

- `addr_mode = 00` – прямая адресация: адрес берётся из второго слова команды `OPND[11:0]`.
- `addr_mode = 01` – косвенная адресация: `OPND[11:0]` загружается в выбранный регистр или используется как смещение, а эффективный адрес берётся из регистра Rn (указанного в `IR_reg`).
- `addr_mode = 10` – не используется (зарезервировано).
- `addr_mode = 11` – не используется (зарезервировано).

#### 5.4. Опкоды

| Команда          | Назначение                         | `opcode` (пример) | Длина (слова) | Операнды                     |
|------------------|------------------------------------|-------------------|---------------|------------------------------|
| INCS Rn          | инкремент по флагу S               | `00000001`         | 1             | Rn = operand1                |
| NOT Rn           | побитовая инверсия                 | `00000010`         | 1             | Rn = operand1                |
| AND Rn, Rm       | логическое И                       | `00000011`         | 1 или 2*      | Rn = operand1, Rm = operand2 |
| SRL Rn           | логический сдвиг вправо            | `00000100`         | 1             | Rn = operand1                |
| MOV [addr] → Rn  | память → регистр                   | `00000101`         | 2             | Rn = operand1, addr = `mem_addr` |
| MOV Rn → [addr]  | регистр → память                   | `00000110`         | 2             | Rn = operand1, addr = `mem_addr` |
| JMP addr         | безусловный переход                | `00000111`         | 2             | addr = `mem_addr`            |
| PUSH Rn          | занести регистр в стек             | `00001000`         | 1             | Rn = operand1                |
| POP Rn           | извлечь регистр из стека           | `00001001`         | 1             | Rn = operand1                |
| HLT              | останов                            | `11111111`         | 1             | операнды игнорируются        |

### 11. Предсказатель переходов A2 (PC+GHR)

| Имя                    | Назначение                                                            | Разрядность | Где используется             |
|------------------------|------------------------------------------------------------------------|------------|-----------------------------|
| **`BRANCH_PREDICT`**   | Блок предсказателя переходов                                          | 1 блок     | Top‑level, рядом с УУ       |

| **`BP_missed`**        | Факт ошибочного предсказания (для анализа и возможной коррекции IP)   | 1          | Предсказатель → УУ          |
